# GarantiaTrack v0.3.0

Repair workshops can now hand customers a thermal intake receipt with private QR tracking.

- Dedicated receipt preview for 80 mm and 58 mm paper, browser printing and Save as PDF.
- Monochrome vector QR generated locally with a quiet zone and Q error correction.
- Intake-only customer projection: internal notes, photos, quotes and contact numbers do not print.
- Copies reuse an existing tab-memory tracking URL. Explicit confirmation precedes renewal, which invalidates old tickets. Reloaded tabs require deliberate renewal because the backend retains only token hashes.
- Live link validation disables unprepared, revoked or expired QR printing.
- Optional APP_PUBLIC_URL for canonical QR destinations during local development, plus a configurable local PORT.

Validation: lint, syntax, build and 30 automated tests passed. An independent decoder verified the SVG at 203 DPI for both paper profiles. Local browser verified receipt navigation, 58 mm dimensions, page rules and private-note exclusion. Physical printer output, paper feed/cuts and phone-camera scanning require a sample on the intended hardware. The integrated browser's host print flow could not be completed automatically.

No database migration, new subscription or external QR service is needed. Existing Supabase data and tracking endpoints are reused. The previous v0.2.0 saved Site version remains the frontend rollback baseline. See docs/receipts.md for printing, privacy and token lifecycle details, and docs/deployment.md for release/rollback instructions.
