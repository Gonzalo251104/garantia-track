# v0.10.4

The browser tab now uses the GarantiaTrack gear-shaped G. The scalable favicon uses the same lime SVG path as the app mark, with an evergreen background for contrast. The browser preview showed a recognizable G at 16 × 16 and 32 × 32 CSS pixels on light and dark backgrounds.

PR #72 passed application CI. This release requires no dependencies or database migrations. Follow the [deployment guide](../deployment.md) to publish the approved commit and verify the favicon and release metadata in Pages.
