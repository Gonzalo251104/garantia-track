# GarantiaTrack v0.2.0

First published pilot for console and controller repair workshops.

- Responsive intake, order dashboard, printable receipt and CSV export.
- Email authentication, workshop onboarding and password recovery with Supabase Auth.
- Transactional orders, workshop isolation, stale-edit detection and idempotent intake.
- Private compressed photo evidence with reserved upload slots and expiring viewing URLs.
- Rotating and revocable customer tracking links with minimal public information.
- English source/documentation, Spanish interface and PR-based Gitflow.

Validation: lint, syntax checks, 22 automated tests, browser build and live anonymous Supabase smoke. Authenticated local intake, photo persistence and tracking were verified with fictional data. Production checks are recorded separately after deployment.

This is a pilot, not a complete workshop ERP. The list loads 500 recent orders. Staff invitations, billing, automated WhatsApp, QR printing and offline operation are outside this release. Default Supabase email delivery is restricted; configure custom SMTP before inviting people outside the project team. No production customer data should be collected before reviewing backups, recovery and retention.

No new schema migration is required when the initial workshop_backend migration is already applied. See docs/deployment.md for publishing, callback configuration and rollback. Source archives do not contain a configured deployment: install dependencies and build with your own public Supabase settings.
