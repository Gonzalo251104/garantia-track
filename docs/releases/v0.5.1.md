# v0.5.1

The active workshop name is visible in the workspace header on mobile and desktop. Long names wrap without covering the sign-out control, and untrusted names are escaped in text and attributes.

Missing or inaccessible authenticated orders now show neutral guidance to check the link and the current workshop, without implying an order was reset or revealing another tenant's records.

Validation: lint, syntax checks, 45 tests and production build passed for the feature. Local browser QA covered the unavailable-order route and an 80-character workshop name at 320 px and 1280 px. A phone check on the published release remains part of acceptance.

No database migration, Auth URL change, key rotation or Storage policy change is required. The existing Site origin and Supabase project remain in use. Draft Vault recovery CLI work in PR #26 is excluded. Complete independent project recovery and external email onboarding remain unresolved; keep pilot tests fictional.

This release also includes the recovery-plan documentation integrated since v0.5.0. Those documents describe partial drills and limitations, not certification of a complete recoverable backup.
