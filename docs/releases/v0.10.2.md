# v0.10.2

The public application opens the authenticated workshop without demo entry points, sample placeholders or fictional-pilot instructions. New workshops receive empty-state guidance. Page metadata describes the product, and workspace copy avoids unmeasured time-saving claims.

## Scope

- Demo mode requires explicit loopback-only development opt-in. Public connected builds ignore that setting and stored demo markers.
- Private customer tracking remains available through existing links. Authentication, workshop membership, photo privacy, records and original QR expiry are unchanged.
- Local development fixtures and existing QA records are retained. Repository cleanup is a separate owner-reviewed task.
- No migration, dependency update, SMTP change or paid service is required.
