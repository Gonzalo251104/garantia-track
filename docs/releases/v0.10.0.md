## User-facing change

Reception offers **Consola**, **Mando** and **Otro**, storing `console`, `controller` and `other`. Console remains the default, and the existing model/customer/contact/issue fields remain required. Describe the equipment in Modelo; there is no new custom-category field or type editor for saved orders.

The labeled native radio group supports keyboard selection, 48 px targets, 16 px labels and wrapping on narrow screens. A shared mapping labels Other correctly in order lists and thermal/PDF receipt data; order/tracking views use a generic equipment icon. Existing CSV columns remain unchanged and retain the entered model. Unknown values display as Equipo instead of an incorrect type, but intake and PostgreSQL still reject them.

Implemented through PR #59, merged into develop at `53c65169c84d8155faaab5ec15bc01b007590f63`. Release preparation preserves that runtime, tests and exact migration; only version/changelog/documentation metadata changes. No SDK/dependency update, key lookup, new access grant, paid service or framework change is required.
