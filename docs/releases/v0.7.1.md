# v0.7.1

Release candidate prepared on 2026-11-04, America/Lima. Preparation does not create a tag, publish a GitHub release or deploy Sites. Public v0.7.0 remains at canonical main `60cd2eacb6fe12a3e6b5d31183bb79c081d7c05a` until those separate steps complete.

## User-facing change

Switching internal screens no longer replaces the workspace navigation with **Conectando con tu taller**. Destination-specific loading stays inside the workspace, keeping the menu available. The connection screen remains for initial session setup. Reception no longer downloads up to 500 orders; detail and ticket routes request the selected order with workshop and number filters. The orders dashboard still refreshes its recent list before search/export.

When a workshop is already known, fresh membership and required order reads run concurrently instead of sequentially. The checked membership gates display; a previous workshop ID is only a query hint. Changed/removed workshop membership discards old data, list totals and recovered receipt links. Navigation/account generations discard late results. Missing orders and provider failures do not fall back to cached private records. Direct reception/detail entry does not present a partial list count as the total.

Implemented through PR #47, merged into develop at `dace08262349711b864ea7934f14ef5b7d4512e8`. This is a performance patch over v0.7.0. No database migration, dependency update, Auth/SMTP change, key rotation, new persistent private-data cache or Storage policy change is required. Existing version-checked mutations, private photos and tracking expiry remain unchanged. Draft Vault recovery PR #26 remains excluded.
