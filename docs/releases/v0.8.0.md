## User-facing change

The connected mobile and desktop **Taller** navigation opens a dedicated settings page instead of returning to orders. The current owner can edit the workshop name, save explicitly, see confirmation/header/sidebar updates and recover the saved name after navigation/reload. Technicians have a read-only name and ownership explanation. Settings uses fresh membership data without downloading the recent order list. Existing demo tracking navigation is preserved; a direct demo settings route is read-only.

Names are trimmed, validated to 2–80 characters without controls, and rendered safely. Unchanged names do not write. Failures retain the draft; a concurrent expected-name mismatch asks for reload rather than overwriting another session. Duplicate/late responses are guarded. Button and Enter saves restore field focus when appropriate without stealing focus that moved elsewhere.

Implemented through PR #50, merged into develop at `1c12da8210602a880cdbd506fc1c5d3b6b8888c0`. The new name appears in the workspace, live tracking and subsequently prepared tickets. Existing downloaded/printed documents retain their previous text. No ownership transfer, role/invite management, dependency update, Auth/SMTP change or paid service is introduced. Draft recovery PR #26 remains excluded.
