# v0.5.0

Receipt PDFs are created in the browser with the existing tracking QR and link. Supported devices can share the file through their native share sheet; otherwise download it and attach it manually. Sending and recipient selection remain user-controlled. WhatsApp text sharing is also available separately.

This release adds no database migration. PDF content contains personal intake information and a bearer link; verify recipients before sharing. Latin text is supported by the built-in PDF font; unsupported characters are replaced. Test file sharing and the WhatsApp handoff on the intended phone and printer.

Validation: lint, syntax, 43 tests, build and a rendered fictional PDF. See `docs/receipts.md` and `docs/product-review.md` for details.
